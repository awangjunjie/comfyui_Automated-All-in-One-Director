# 开源打包说明（20260807）

本目录即为 GitHub 仓库根目录内容，对应：
https://github.com/AIMixer/ComfyUI_MiniMaxH3_Director

## 同步到 GitHub

```bash
# 若已有远端仓库：
cd ComfyUI_MiniMaxH3_Director_opensource_20260807
git init
git add .
git commit --trailer "Co-authored-by: Cursor <cursoragent@cursor.com>" -m "Release: MiniMax H3 Director full studio 20260807"
git branch -M main
git remote add origin https://github.com/AIMixer/ComfyUI_MiniMaxH3_Director.git
git push -u origin main
```

或直接用 GitHub Desktop / \gh\ 把本文件夹作为仓库根目录推送。

## 包内不含

- MiniMax H3 模型权重（体积过大，见 README 下载链接）
- TE-Speed / KJNodes 等第三方加速节点
- \__pycache__\ / 本地缓存 / \.env\

## 安装（终端用户）

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/AIMixer/ComfyUI_MiniMaxH3_Director.git
pip install -r ComfyUI_MiniMaxH3_Director/requirements.txt
```

示例工作流见 \example_workflows/\。
